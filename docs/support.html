About Volocal

Volocal is a fully local voice AI assistant for iOS. Speech-to-text, the language model, and text-to-speech run on the iPhone. After you download model files from Hugging Face, voice chat does not need the internet.

Frequently Asked Questions

What devices are supported?

iOS 17+ on a physical iPhone with a Neural Engine. Not the Simulator. This fork is meant to be sideloaded with SideStore into a real app slot (not LiveContainer as a guest — microphone echo cancellation is unreliable there).

How much storage space does Volocal need?

The app is small. Speech + voice packs are roughly 0.5–1 GB depending on engines. The language model is whatever GGUF you pick (often 1–4 GB). Downloads happen on first launch over Wi-Fi.

Does Volocal work offline?

Yes, after model files are downloaded. Hugging Face is used only to fetch or list those files, not to send your voice.

Can I change the language model or voice engines?

Yes. Onboarding and the in-app CPU / waveform buttons let you pick a GGUF from Hugging Face and switch STT (Parakeet EOU or Nemotron) and TTS (PocketTTS or Kokoro).

How do I install a build without a Mac?

Push this repo to GitHub, run the “Build IPA” workflow, download the IPA artifact, and install it with SideStore. SideStore re-signs with your Apple ID.

The app is not responding or is very slow. What should I do?

On-device inference is heavy. Close other apps, use a smaller GGUF, and keep PocketTTS + Parakeet EOU 320 unless you have RAM headroom. GetMoreRAM / increased-memory-limit raises the memory cap; it does not add physical RAM.

Report a Bug

If you encounter a bug or unexpected behavior, please open an issue on GitHub: github.com/kimjonauw/volocal/issues. Include a description of the problem, your iPhone model, and your iOS version to help us investigate.
